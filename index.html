What it is
🔑

Wallet + ENS identity

Your identity is an ENS name you actually own. Login signs a UUID + timestamp (EIP-191), the server checks it against the current on-chain owner — no phone number, no email.

🐝

Auth via honesty

A 17-question honesty vector, ML-DSA-signed, hashed and compared on verify — you cannot steal someone's answer to "who is your mother" the way you can steal a password.

🔒

Post-quantum E2E

Real RustCrypto ML-KEM/ML-DSA (FIPS 203/204), Matrix's vodozemac Double Ratchet as the trusted base, hybrid session keys derived per-direction via HKDF — not hand-rolled crypto.

Quick start
# create your identity (17 honesty questions)
etherhive init

# start all sidecars — vpn, crypt, mesh, ircd
etherhive up

# real E2E, auto-bootstraps a ratchet session
/dm alice.eth hey — this is end-to-end

# wallet-signed login, verified against the current ENS owner
/login vitalik.eth
